How to get a free API key (2 min)
  1. Go to console.cloud.google.com and sign in.
  2. Create a project (top bar → New Project → any name → Create).
  3. Search "Places API (New)" in the top search bar → Enable. (Google asks for billing, but the free monthly credit easily covers this use.)
  4. Menu → APIs & Services → Credentials → Create Credentials → API key.
  5. Copy the key, paste it above. Optionally restrict it to "Places API (New)".

Your key stays on this device (browser storage). It's only ever sent directly to Google.
