How to get a free API key (2 min)
  1. Go to console.cloud.google.com and sign in.
  2. Create a project (top bar → New Project → any name → Create).
  3. Search "Places API (New)" in the top search bar → Enable. (Google asks for a billing account, but gives free monthly credit that easily covers personal use of these lookups.)
  4. Menu → APIs & Services → Credentials → Create Credentials → API key.
  5. Copy the key and paste it above. Optionally edit the key and restrict it to "Places API (New)" for safety.

Your key is saved only on this device (browser storage). Nothing is sent anywhere except directly to Google.
